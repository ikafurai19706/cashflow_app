# cashflow_app

究極に自分用のキャッシュフロー管理アプリ。

## 概要

とある「人生、宇宙、すべての答え」を掲げるプログラミングスクールの東京校へ通うため、約2年間の上京を計画していた。生活費は貯金とアルバイト収入を中心にやりくりする予定だったため、「今月あといくら使えるのか」を常に把握しながら生活する必要があった。

そこで家計簿アプリを探してみたが、世の中のアプリは家計分析や資産管理など多機能なものが多く、自分が知りたい「固定費やクレジットカードの支払いを考慮した上で、今使ってよい金額」をシンプルに確認できるものは見つからなかった。

それなら、自分に必要な機能だけを備えたアプリを作ってみようと思い、このプロジェクトを始めた。

このアプリは、現在の預金残高だけでなく、クレジットカードの未払い残高や、これから引き落とされる家賃・サブスクリプションなどの固定費を考慮した「自由に使える金額」を、シンプルかつ直感的に把握できるアプリを目指す。

日々の入力は数秒で終わることを重視し、必要最低限の機能に絞ることで、毎日ストレスなく使い続けられる、家計簿というよりはキャッシュフロー管理に近いアプリを開発する。また、本プロジェクトはFlutterを学ぶための実践的な個人開発としても位置付けており、実際に自分が日常的に使うことを前提に改善を重ねていく。
